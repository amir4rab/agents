# Agents

An Agent agnostic platform for managing agents form a easey-to-use dashboard.

## Prerequisites

For developing the backend service (manager service) you need to have 
`go`, `make` and `build-essential`, as such please make sure they are 
available in your environment.

Additionally, for developing the front-end (dashboard) you only need 
the `node` runtime in addition to `pnpm` package manager. 
The angular cli can also be used, but its not a necessary requirement.
